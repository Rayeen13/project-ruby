# Opal’s skinned anime avatar

The rejected procedural humanoid is replaced by an actual VRoid beta avatar mesh, not a generated robot body. Runtime: Three.js r170 GLTFLoader and pixiv three-vrm 3.3.3 (MIT). Vendored module imports are redirected to Ruby’s existing local Three.js build; no CDN request is required at runtime.

Base: Victoria Rubin, a VRoid beta sample distributed as CC0. Retrieved from https://github.com/madjin/vrm-samples/blob/main/vroid/beta/Victoria_Rubin.vrm . Its embedded VRM metadata declares CC0, commercial use allowed and use by everyone. Original bytes SHA256: `b1372131bdbf233f46320146d565f342a7e4f6f4b8f2aefb301f1a283ec07e1e`.

Pixiv’s primary licensing references for the older beta samples:
- https://vroid.pixiv.help/hc/en-us/articles/4402614652569
- https://vroid.pixiv.help/hc/en-us/articles/360014900233

Do not substitute modern VRoid sample/preset terms for this asset’s CC0 grant. Do not describe the base sculpture as originally authored by Project Ruby. The local VRM preserves the original embedded licence metadata. Images are reduced to a maximum 1024-pixel dimension for local runtime size/texture memory; geometry, humanoid skin weights, morph targets and bones remain in the VRM. Packaged asset SHA256: `ad231f4713b25415ffa45123f4eef72ccd731961d98c7a10398822f55d998dae` (8,111,800 bytes).

Ruby adapts the continuous garment mesh into four presentations with cut sleeves, different hem lengths, skinned apron overlays and work glasses. Hair tint, mood/gaze and finger/wave poses are runtime adaptations. Outfit scheduling is local presentation state; the model asset’s sample identity does not become Opal’s DDNA identity/personality.

The runtime model is an open-surface, textured, skinned avatar. A printable static solid is a separate conversion; the old procedural Opal STL is not offered as this model. Original robot STL downloads remain available. Screen-size performance, clipping and appearance need visual acceptance; functional VRM loading alone is not art approval.
