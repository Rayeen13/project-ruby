# In-progress host grounding and expressive VoiceM

This branch is a checkpoint, not a release. The conversation prompt now explicitly grounds the character in Prismy Studio, separates the LLM from character identity, discourages repeated catchphrases, and retains 1800 rather than 1000 characters of paired history. Dialogue policy is bumped to avoid feeding the old incorrect assistant claims back as examples. Existing conversation and identity ownership unit tests pass. Real multi-turn Qwen regression using the reported Opal conversation is still required before release; a longer prompt alone is not evidence of improved dialogue.

Candidate for the first actual Japanese expressive engine: nyosegawa/speech.cpp v0.8.10 with Aratako Irodori-TTS-v4.1-Small-MF, using caption-designed original adult character voices, not scraped actor audio. Japanese-only; use the existing local LangM for English text plus Japanese speech. Model MIT with additional published restrictions against unconsented impersonation and deceptive speech. Preserve those terms, runtime MIT notice, codec MIT and inherited Apache-2.0 notices. No zero-risk legal promise; no anime fine-tunes of unverified provenance.

The GGUF includes codec; pass its local path to prevent implicit runtime downloads. `speech serve PATH --host 127.0.0.1 --port PORT --device auto --threads 2` warms and reuses the model. `/health`, `/v1/models`, and `/v1/audio/speech` are documented in the v0.8.10 docs. Synthesis JSON uses input, voice:none, language:ja, seed, steps:4, speed, instructions, response_format:wav. Caption `instructions` supports original voice design; emoji supports some performance cues. A fixed seed is reproducible per device but does not guarantee a stable voice across sentences without an approved generated reference. Need actual audition before claiming anime quality or latency.

Remaining implementation: optional checksum-verified download card with terms/footprint, bounded warm native server lifecycle with idle unload and exit cleanup, cancellation/disconnect, CPU fallback, actual device reporting, personality/gender-aware caption profiles and acting controls, small Japanese sentence chunks, consented original reference locking after audition, shared compute scheduling, and real Windows CPU smoke plus a physical RTX 2050 trial. Existing Kokoro/Supertonic stock voices are not replaced or relabeled as the new engine yet.
